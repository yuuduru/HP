### issues.json の編集方法

`data/issues.json` を開き、各号のデータを入力します。

#### 変更前（入力待ち）
```json
{
  "number": 82,
  "date": "2011年7月",
  "sections": [
    {
      "sectionName": "巻頭言",
      "articles": [
        {"title": "[不明]", "author": "[不明]"}
      ]
    }
  ]
}
```

#### 変更後（入力済み）
```json
{
  "number": 82,
  "date": "2011年7月",
  "sections": [
    {
      "sectionName": "巻頭言",
      "articles": [
        {"title": "東日本大震災に遭われたあなたへ", "author": "井之川勝"}
      ]
    },
    {
      "sectionName": "特集",
      "articles": [
        {"title": "東日本大震災をめぐって（1）", "author": "芳賀力"},
        {"title": "東日本大震災をめぐって（2）", "author": "芳賀力"}
      ]
    }
  ]
}
```

### PDFの読み方

PDFの各ページはセクション種別（巻頭言・特集・論文・翻訳・聖書研究など）ごとに
各号のデータが**列**として並んでいます。

**読み方のポイント：**
1. 縦書き・右から左に読む
2. 各列の最下段 = 著者名 + 号数（No.XX）
3. 各列の内容 = その号のその欄の記事タイトル
4. `pdf_images/enhanced/` フォルダの画像が読みやすい

### よく登場するセクション名
- 巻頭言（各号1本）
- 特集（各号の特集テーマ）
- 論文（学術的記事）
- 翻訳（外国語文献の翻訳）
- 聖書研究 / 聖書講義（連載）
- 聖霊解（lectio spiritualis、連載）
- パンの耳（短文コラム）
- ティーブレイク
- 牧会者の証言
- 本のオアシス（書評）
- 海外ニュース

## フェーズ2: HTML生成 → WordPress投入

### ステップ1: HTML再生成
```bash
cd /Users/koji/HP/kaichokyo
python3 generate_html.py
```
→ `output/database_page.html` が更新される

### ステップ2: プレビュー確認
```bash
open output/preview_standalone.html
```
ブラウザで表示確認

### ステップ3: WordPress固定ページ作成
1. http://www.kaichokyo.jp/wp-admin/ にログイン
2. **固定ページ > 新規追加**
3. タイトル: `季刊教会 総目次`
4. **「+」ボタン > カスタムHTMLブロック**を追加
5. `output/database_page.html` の内容を全コピー&ペースト
6. **下書き保存** → プレビューで確認
7. 問題なければ **公開**

### ステップ4: CSS追加
1. WordPress管理画面 > **外観 > カスタマイズ > 追加CSS**
2. `output/database_page_style.css` の内容を全コピー&ペースト
3. **公開**

### ステップ5: メニューに追加
1. **外観 > メニュー**
2. 「季刊教会 総目次」固定ページをメニューに追加

## フェーズ3: トップページ最新号ウィジェット

### 手順
1. `output/frontpage_widget.html` を開く
2. `<!-- ▼▼▼ 最新号の目次をここに入力 ▼▼▼ -->` 部分を最新号データで更新
3. トップページの固定ページを編集
4. カスタムHTMLブロックとして貼り付け
5. 号数・日付・リンク先URLを確認して更新

### 毎号の更新手順
1. `data/issues.json` に新号データを追加
2. `python3 generate_html.py` を実行
3. WordPress管理画面で「季刊教会 総目次」ページを編集
4. カスタムHTMLブロックの内容を新しい `database_page.html` の内容で置換
5. トップページの `frontpage_widget.html` も更新
